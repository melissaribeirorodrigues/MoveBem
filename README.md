
# MoveBem<img width="100" height="100" alt="icon44" src="https://github.com/user-attachments/assets/d2433b66-5ace-469f-b907-d137b0c9cd3d" />
Aplicativo mobile de saúde e bem-estar desenvolvido em Flutter
MoveBem é um aplicativo voltado para o gerenciamento de rotinas saudáveis, permitindo aos usuários acompanhar exercícios físicos, controlar a ingestão de água e manter um histórico diário de suas atividades.

# MoveBem
Aplicativo mobile de saúde e bem-estar desenvolvido em Flutter
MoveBem é um aplicativo voltado para o gerenciamento de rotinas saudáveis, permitindo aos usuários acompanhar exercícios físicos, controlar a ingestão de água e manter um histórico diário de suas atividades.

 Funcionalidades Principais
 - Sistema de login e autenticação de usuários
 - Gerenciamento de exercícios e rotinas personalizadas
 - Registro e controle de consumo de água
 - Histórico diário de atividades
 - Interface moderna com splash screen animada
 
 Tecnologias Utilizadas
Frontend: Flutter (Dart)
Backend: PHP com arquitetura MVC
Banco de Dados: MySQL
Padrão de Projeto: CRUD RESTful
